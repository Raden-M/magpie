# MIT license

Date: 2026-07-28
Status: accepted

## Context

Left open during specification. Library choices deliberately kept both paths available.

## Decision

Release under MIT.

## Alternatives rejected

AGPL-3.0 would protect a self-hosted tool from closed SaaS forks, at the cost of adoption and
reuse. For a single-user tool whose whole premise is that you run it yourself, the fork risk it
guards against is largely theoretical.

## Consequences

Anyone may fork, including commercially, without contributing back.
